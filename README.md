# Тестовое задание: тестирование desktop-приложения (сигналы по TCP)

## Что внутри

- `simulator.py` — сервис-симулятор из условия (10 сигналов, синусоида, порт 2001).
  Нужен, чтобы тесты запускались без реального приложения.
- `service_client.py` — TCP-клиент к сервису сигналов.
- `test_service_contract.py` — контрактные тесты данных: 10 сигналов, уникальные ID,
  валидные поля, изменение значений во времени, негативный кейс (сервис недоступен).
- `test_gui_display.py` — критичный сценарий: подключение и отображение 10 сигналов,
  кросс-проверка ID с сервисом, обновление по кнопке.
- `ui_adapter.py` — доступ к GUI (изолирован: Windows pywinauto → Linux dogtail/AT-SPI).
- `config.py`, `conftest.py`, `helpers.py`, `pytest.ini` — конфиг, фикстуры, утилиты ожидания, настройка pytest.

## Запуск

```bash
pip install -r requirements.txt

# Контрактные тесты (не требуют GUI, симулятор поднимается сам):
pytest -v test_service_contract.py

# GUI-тесты (нужен путь к приложению):
#   Windows (PowerShell):  $env:APP_PATH="C:\path\signal_app.exe"
#   Linux:                 export APP_PATH=/path/signal_app
pytest -v test_gui_display.py

# Всё сразу:
pytest -v
```

Ожидаемый результат без `APP_PATH`: **5 passed, 3 skipped**.
JUnit-отчёт пишется в `report.xml`.

## Допущения и ограничения

- Реального приложения нет, поэтому источник данных — `simulator.py` (мок).
  Контрактные тесты проверяют **данные и TCP-слой**, а не само приложение (SUT).
- Формат кадра принят как **JSON-строки** (по объекту на строку).
- Структура таблицы принята как 5 столбцов: ID, имя, значение, качество, время.
  `auto_id` контролов — заглушки и уточняются на реальном приложении.
- Целевая ОС разработки — Linux (C++/Qt); текущий `ui_adapter` под Windows (pywinauto).
  Для Linux нужен адаптер dogtail/AT-SPI. Без GUI/селекторов UI-тесты пропускаются.

## Как адаптировать под реальное приложение

1. **Протокол.** Если кадр не JSON-lines, поправьте разбор в `service_client.py`
   и формат в `simulator.py`.
2. **GUI.** В `ui_adapter.py` укажите реальные `auto_id` таблицы и кнопок
   (Inspect.exe / Accessibility Insights). Для Linux (Qt) перепишите класс на
   dogtail/AT-SPI, сохранив методы `rows / click_connect / click_refresh`.

## Что проверяется (критичный сценарий)

После нажатия «Подключиться» приложение получает по TCP 10 сигналов и отображает их
(ID, имя, значение, качество, время); ID уникальны; значения — числа в диапазоне.
Дополнительно: набор ID в таблице совпадает с сервисом; «Обновить» обновляет данные.
